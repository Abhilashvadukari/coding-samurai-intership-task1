
# Tic-Tac-Toe AI

## Description
A Tic-Tac-Toe game with an AI opponent using the Minimax algorithm.

## Features
- Human vs AI gameplay
- AI never loses
- Minimax algorithm implementation

## Run the Project

```bash
py tictactoe.py
```

## Skills Used
- Python
- Game Logic
- Artificial Intelligence
- Minimax Algorithm
